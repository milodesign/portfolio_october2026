# Instrucciones del proyecto — Portfolio de Camilo Morales

## Objetivo

Desarrollar un portfolio web profesional para Camilo Morales, con una identidad visual editorial, minimalista, sofisticada y orientada a mostrar su experiencia real en diseño gráfico, diseño editorial, branding y contenido digital.

## Estructura del proyecto

- `index.html`: página principal.
- `assets/css/`: hojas de estilo propias.
- `assets/img/profile/`: fotografía de perfil.
- `assets/img/templates/`: referencias visuales de diseño.
- `assets/img/gallery/`: imágenes opcionales de trabajos.
- `assets/js/`: scripts propios, si son necesarios.
- `.opencode/agents/portfolio-designer.md`: agente especializado del proyecto.

Respeta las carpetas existentes y examina sus contenidos antes de modificarlas.

## Tecnologías

- HTML5 semántico.
- CSS3.
- JavaScript.
- Bootstrap, con la versión y los recursos comprobados directamente en la documentación oficial: https://getbootstrap.com/docs/6.0/guides/quickstart/

No adivines versiones, enlaces CDN, atributos SRI ni APIs. Si no puedes verificar la documentación, informa de la limitación.

No añadas frameworks ni dependencias innecesarias.

## Diseño

- Prioriza una estética editorial y minimalista.
- Analiza las referencias de `assets/img/templates/` antes de definir la interfaz.
- Utiliza la fotografía de `assets/img/profile/` cuando esté disponible.
- Utiliza `assets/img/gallery/` únicamente cuando las imágenes sean adecuadas.
- No presentes referencias visuales como trabajos propios.
- Mantén consistencia tipográfica, jerarquía visual y espacios en blanco.
- Diseña para móvil, tablet y escritorio.

## Contenido y veracidad

El CV es la fuente principal para la información profesional.

No inventes clientes, proyectos, fechas, cargos, métricas, premios, certificaciones ni competencias.

Distingue entre experiencia laboral, proyectos personales y habilidades en aprendizaje.

No publiques el archivo original del CV ni otros documentos privados como parte del sitio.

## SEO y accesibilidad

Utiliza títulos y descripciones precisos, HTML semántico, jerarquía de encabezados, textos alternativos, metadatos para compartir, enlaces descriptivos y datos estructurados únicamente cuando correspondan.

Utiliza palabras clave de diseño y desarrollo web solo cuando estén respaldadas por la experiencia o los proyectos reales.

No prometas posiciones en buscadores ni recomendaciones garantizadas de sistemas de IA.

Verifica contraste, teclado, foco visible, navegación móvil y reducción de movimiento.

## Calidad del código

- Mantén CSS y JavaScript separados de HTML cuando sea práctico.
- Evita duplicaciones, estilos inline innecesarios y dependencias superfluas.
- Comprueba todas las rutas de recursos.
- No dejes botones sin funcionalidad.
- No crees formularios de contacto que aparenten funcionar si no pueden enviar mensajes.
- No sobrescribas ni elimines archivos sin necesidad.
- Ejecuta las comprobaciones disponibles y comunica cualquier limitación.

## Forma de trabajo

Inspecciona antes de implementar. Presenta un plan breve y luego desarrolla el sitio por fases.

Al terminar, informa de los archivos modificados, las decisiones técnicas, la verificación de Bootstrap, las pruebas realizadas y las tareas pendientes.
